# Workspace Agent Rules

Before starting any work in this repository, read [manual/MANDATORY_RULES.md](manual/MANDATORY_RULES.md).

Core workspace expectations:
1. Report the reason and scope before modifying existing source files, then wait for approval.
2. Never delete existing source without explicit user approval.
3. Do not run build, deploy, or GitHub push commands without user approval.
4. If debugging reveals problems, report the issue and the visible symptoms before fixing.
5. Treat the manual as a required pre-work checklist for every task.

Priority order:
1. System and developer instructions
2. This repository's mandatory rules
3. Task-specific user requests

If a rule conflicts with higher-priority instructions, follow the higher-priority instructions and note the exception in your response.
